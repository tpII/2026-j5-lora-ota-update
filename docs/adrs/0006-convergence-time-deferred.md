# M1 no se mide en el primer informe

El cronograma del E1 (§5.1) incluye para el primer informe las primeras mediciones del tiempo de convergencia (M1) con dos nodos. M1 va desde que la computadora entrega la imagen al origen hasta que el último nodo confirma la activación, así que necesita la transferencia y la activación, que el mismo E1 programa para noviembre. Por eso el primer informe no mide M1: se mide recién cuando exista la transferencia.

## Opciones consideradas

- Una transferencia mínima de una imagen opaca, sin firma ni VM: adelanta trabajo de noviembre para medir algo que todavía no es M1.
- Una estimación de M1 a partir del *goodput* de la prueba de capacidad, para validarla después con la transferencia.
